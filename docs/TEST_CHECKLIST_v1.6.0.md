# 宠了么 v1.6.0 真机 / 模拟器 测试清单 + 测试报告模板

> 两套包：真机用 `app-arm64-v8a-release.apk`，雷电/模拟器用 `app-x86_64-release.apk`。  
> 安装步骤见 `BUILD_INSTALL_RUNBOOK.md`。

---

## 一、安装与启动

- [ ] 真机：arm64 包装上能打开，无闪退
- [ ] 雷电：x86_64 包装上能打开（无摄像头也能装、能进首页）
- [ ] 首次启动无崩溃；权限弹窗（相机/麦克风/存储）正常出现并可授权
- [ ] 关于页能看到「设备指南」入口，且显示 Apache-2.0 合规信息

---

## 二、设备能力 3 档弹窗（需求 6）

- [ ] 高端机：识别为「高」，默认开启实时体态，无降级提示
- [ ] 中端机：识别为「中」，提示可按性能降级
- [ ] 低端/A13 档设备：识别为「低」，强制每 3 帧推理（实测帧率不掉到卡顿）
- [ ] 弹窗文案清楚，用户能看懂「当前档位 + 影响」

---

## 三、模型远程下载（需求 2）

- [ ] 首次进入体态功能触发模型下载，有进度/loading
- [ ] 下载完成后本地缓存，二次进入不需重下
- [ ] 断网/下载失败时**降级**（相机/录像/音频正常，只是不出情绪，不闪退）
- [ ] 下载失败有明确提示，不是静默失败

---

## 四、实时视频体态推理（需求 4/5）

- [ ] 相机预览正常显示（竖屏，无拉伸/旋转错）
- [ ] 画面里放真猫/真狗，能检测到（`hasPet=true`）并出情绪文案
- [ ] 24 关键点正确（骨架/姿态识别合理，不是乱点）
- [ ] A13 档：强制每 3 帧，画面不卡、不丢帧
- [ ] 无宠物时：不误识别（情绪为空/“未识别”）
- [ ] 暗光：亮度低于阈值自动禁用体态，UI 提示「暗光已关闭体态」

---

## 五、SSD 前置检测（需求 3）

- [ ] 画面无猫狗时，跳过 HRNet（CPU/帧率更省）
- [ ] 画面出现猫狗，恢复 HRNet 推理
- [ ] SSD 模型缺失时降级为“始终有宠物”，流程不卡

---

## 六、音画同步录像 + 边录边叫（需求 8）

- [ ] 开始录像：真机有声音、有画面、情绪文字烧录进视频
- [ ] 停止录像：返回 MP4 路径，文件可播放
- [ ] 播放导出 MP4：画音同步（嘴型/动作不与声音错位 > 200ms）
- [ ] 边录边叫：播放选中叫声时，该叫声**同时录进**视频文件（导出后能听到）
- [ ] 录像中切换叫声/停止叫声，录制继续不受影响
- [ ] 录像中 App 不发热失控、不 OOM、不 ANR

---

## 七、社交分享（需求 9）

逐一点测，已安装则能跳对应 App，未安装则走系统分享/隐藏按钮：

- [ ] TikTok / 抖音
- [ ] Instagram
- [ ] X (Twitter)
- [ ] Facebook
- [ ] YouTube
- [ ] 系统分享（兜底）
- [ ] 分享的是**导出 MP4 文件**，不是链接/文本
- [ ] 没装对应 App 时按钮不崩溃、有合理降级

---

## 八、原有模块回归（需求 10）

- [ ] 语音翻译 / 叫声库等原有功能**未受影响**（本次只新增捕获/分享通道）
- [ ] 之前 `${f.poseEmotion}` 渲染 bug 已修复（相关页面正确显示情绪，不是字面 `${...}`）
- [ ] 内置 TTS 已移除（无残留调用/崩溃）
- [ ] 免责声明图标按钮可点开，内容正确

---

## 九、稳定性 / 性能

- [ ] 连续录像 3 分钟不崩、不严重发热
- [ ] 来回进出体态页多次不内存泄漏/不崩
- [ ] 后台切回前台不丢相机、不黑屏
- [ ] 低配机（A13 档）帧率可接受

---

## 十一、必带日志（出问题时）

真机/模拟器抓日志：

```bat
adb logcat -s CameraRec  MeowWoof  Flutter  *:E > logcat.txt
```

重点看 `CameraRec` 标签（相机/推理/录像链路）与 `Flutter` 异常。
